Six vector instructions replaced 32 scalar stores

A bounded Arm NEON patch doubled the isolated Q8_0 activation quantizer and preserved every tested output byte. Whole-model inference stayed neutral, so Pareto64 claims only the measured hot path win. The complete three-patch series was then revalidated on llama.cpp b10216: every targeted test passed and all 12 paired Q8 rounds improved. A broader upstream-equivalent Arm CPU lane then passed the complete build and all 47 executed tests. Finally, the exact selected service cleared every b10216 upgrade gate and is exposed only through a source/build-bound opt-in launch contract.
